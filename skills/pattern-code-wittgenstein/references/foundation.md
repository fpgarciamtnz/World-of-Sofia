# Foundation

This skill keeps one Wittgensteinian habit and rejects one common misuse.

Keep:

- Look for families of use, not just matching words.
- Judge meaning through public use: call sites, tests, collaborators, schemas, and observable effects.
- Treat shared repository practice as the background that makes a precedent relevant.

Reject:

- Do not treat family resemblance as proof that code should be reused.
- Do not assume every similar-looking case hides one perfect abstraction.

Operational translation:

- Family resemblance is a candidate-generation tool.
- Bounded context is a hard filter.
- Naming-only similarity is weak evidence.
- Repeated tests and stable interfaces are strong evidence.
- A local duplicate can be better than a premature shared abstraction.

This skill is intentionally conservative. It uses philosophical framing only to improve engineering judgment, not to replace it.
