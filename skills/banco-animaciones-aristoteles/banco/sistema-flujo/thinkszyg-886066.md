# Esqueleto de briefing para un anuncio de móvil

Seis pasos para dirigir a la IA en un spot: estilos y muestras a elegir, solo el texto dado, subagentes por capítulo, hojas de contactos, tres bandas sonoras y autocomprobación.

Autoría: [@thinkszyg](https://x.com/thinkszyg) · [post original](https://x.com/thinkszyg/status/2104525558050886066)

## Prompt

```text
想自己试，开工简报的骨架：
1. 先给 3 个风格帧、10 秒样片、30 秒配乐试听，等我选
2. 上屏文字只用我给的文案表
3. 按章节拆给子代理，每人只改自己的文件
4. 每段都出联系表和接缝逐帧图，你先自己看
5. 配乐至少给 3 种风格
6. 成片跑自检，写成报告。
```
