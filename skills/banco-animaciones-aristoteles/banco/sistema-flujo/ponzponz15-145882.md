# Landing page convertida en vídeo vertical de nueve escenas

Flujo para pasar una landing a vídeo vertical de nueve escenas, con textos y logo rehechos y animación HTML/CSS/JS capturada fotograma a fotograma a 60 fps.

Autoría: [@ponzponz15](https://x.com/ponzponz15) · [post original](https://x.com/ponzponz15/status/2106307182019145882)

## Prompt

```text
1. LPを9つの場面に分解して縦型動画の構成に。コピーは一字一句そのままWebフォントで組み直し、ロゴはSVGで描き直し。

2. 元画像の人物写真は150px前後で、拡大すると崩れる → 高解像度に再生成 Codex呼び出し

3. 動きはHTML/CSS/JavaScript（髪の揺れはWebGL）で書いて、ブラウザで1フレームずつ撮影して60fpsに。動画編集ソフトは不使用。BGMはLyria 3 Pro。
```
