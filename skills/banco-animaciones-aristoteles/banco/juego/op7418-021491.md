# Momento estelar de móvil: inicio de plantilla recortado

Arranque de un prompt en chino para una animación de recompensa de juego móvil en HTML de un solo archivo; se corta tras la primera sección de estilo.

Autoría: [@op7418](https://x.com/op7418) · [post original](https://x.com/op7418/status/2104085539419021491)

## Prompt

```text
帮我做一个原创的手游「高光时刻」动效：[主体，例如：开宝箱 / 段位晋升 / 成就解锁 / Boss 掉落 / 角色升级]。
做成一个可以直接打开的单文件网页（HTML + CSS + JS），点一下就能完整播放，效果对标商业手游的结算 / 奖励演出。

【世界观与风格】
- 原创美术，不要模仿任何现有游戏的
```
