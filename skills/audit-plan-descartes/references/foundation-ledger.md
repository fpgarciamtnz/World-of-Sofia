# Foundation Ledger Reference

The core discipline of this skill is simple: do not let an inferred claim silently become a planning fact.

Useful prompts:

- What is directly observed?
- What is only inferred?
- What evidence would upgrade this assumption?
- If Grill Me Aquinas supplied essence context, does the plan preserve project essence or only match surface wording?
- Is the plan treating an accident, habit, or open potency as if it were a project law?
