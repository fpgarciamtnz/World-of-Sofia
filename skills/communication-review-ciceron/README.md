# Communication Review Ciceron

Communication Review Ciceron is a Cicero-inspired skill for reviewing messages as purposeful acts. It explains what a message says, what it is doing, what a receiver may understand, where it creates friction, and how to rewrite it with clearer intent.

## What it does

- Separates observed wording from inferred intent and recommended revision.
- Reviews goal, speech act, audience, emotional impact, rhetorical position, tension, scoring, and reformulation.
- Gives straight feedback without pretending to read minds.
- Preserves necessary firmness while reducing avoidable confusion, face threat, and ambiguity.
