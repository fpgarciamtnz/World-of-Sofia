# Sofia

Philosopher idea: Aristotle's phronesis, practical wisdom, is the judgment that sees which virtue a particular situation calls for, in what measure, and when; Sofia applies it to the family by choosing which habits a task needs, in what order, and leaving out the rest.

Practical use: Call Sofia when work needs more than one Sofia skill, when you are not sure which one fits, or by name to see the family. It reads the request, loads the specialists the outcome needs, carries each one's findings to the next, and hands back the deliverable you asked for, with the specialists it used and why.

## What it does

- Picks the smallest set of specialists that changes the outcome, and loads a single one directly when that is enough.
- Orders them where one's output is another's input: meaning before planning, precedent before code, the real diff after it, the audience last.
- States what each specialist must hand the next, keeps every verdict attributed, and resolves disagreements from evidence or asks you.
- Lists the family when called without a task.

## Distribution boundary

This folder must stay self-contained. It names the other Sofia skills and loads them when they are installed; when one is missing, it says so and names what goes unchecked.
