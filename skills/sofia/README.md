# Sofia

Philosopher idea: Aristotle's phronesis, practical wisdom, is the judgment that sees which virtue a particular situation calls for, in what measure, and when; Sofia applies it to the family by choosing which habits a task needs, in what order, and leaving out the rest.

Practical use: Call Sofia when work needs more than one Sofia skill, when you are not sure which one fits, or by name to see the family. It tells which phase the work is in (make it work, make it efficient, make it look right), loads the specialists that phase needs, looks for the gaps that phase leaves, and hands back the deliverable you asked for, with the phase reached and the gaps left for the next.

## What it does

- Tells the phase from the evidence: phase 1 until an oracle confirms that a real case works end to end, phase 2 to get the same result with less, and phase 3 to make it organized and clear. The phases run in that order, because each one guards the next.
- Gives each phase its leads (Aquinas, Magallanes, and Descartes to make it work; Kondo, Hegel, and Descartes to make it efficient; Ciceron, Ortega, and Kondo to make it look right), its gaps to look for, and a condition that closes it, in `references/phases.md`.
- Picks the smallest set of specialists that changes the outcome, and loads a single one directly when that is enough.
- Orders them where one's output is another's input: meaning before planning, precedent before code, the real diff after it, the audience last.
- States what each specialist must hand the next, keeps every verdict attributed, and resolves disagreements from evidence or asks you.
- Lists the family when called without a task.

## Distribution boundary

This folder must stay self-contained. It names the other Sofia skills and loads them when they are installed; when one is missing, it says so and names what goes unchecked.
